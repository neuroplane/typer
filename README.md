# Typer - Обучающая игра для Raspberry Pi

## Описание проекта

**Typer** — это интерактивный обучающий скрипт для Raspberry Pi, разработанный для детей. Программа сочетает обучение математике и базовым командам Linux с развлечением — просмотром мультфильмов.

### Основные возможности

- 🧮 **Математические задачи**: Решение простых примеров на сложение (числа от 1 до 5)
- 💻 **Изучение команд Linux**: Запоминание базовых команд терминала
- 🎬 **Воспроизведение видео**: Просмотр мультфильмов после выполнения заданий
- 📊 **Система прогресса**: Автоматическое увеличение сложности с каждым прохождением
- 🔄 **Циклическое выполнение**: Автоматический перезапуск после просмотра видео

## Требования

### Аппаратное обеспечение

- Raspberry Pi (любая модель с поддержкой GPIO)
- USB-накопитель с файловой системой, смонтированный в `/media/pi/RASPBERRYPI`
- USB-накопитель с видеофайлами, смонтированный в `/media/pi/HOME128`

### Программное обеспечение

- **ОС**: Raspberry Pi OS (или любая Linux-система)
- **Интерпретатор**: Bash
- **Видеоплеер**: `omxplayer` (для воспроизведения видео)
- **Утилиты**: `shuf` (для случайного выбора файлов)
- **Права**: Доступ к `sudo` для создания директорий

## Установка

### Шаг 1: Клонирование репозитория

```bash
git clone <repository-url>
cd typer
```

### Шаг 2: Установка прав на выполнение

```bash
chmod +x typer.sh
```

### Шаг 3: Подготовка USB-накопителей

1. **USB-накопитель для данных**:
   - Отформатируйте USB-накопитель в формате FAT32 или ext4
   - Смонтируйте его в `/media/pi/RASPBERRYPI`
   - Убедитесь, что пользователь `pi` имеет права на чтение/запись

2. **USB-накопитель с видео**:
   - Создайте структуру папок на USB-накопителе:
     ```
     /media/pi/HOME128/Videos/
       ├── Папка1/
       │   ├── мультик1.mp4
       │   └── мультик2.mp4
       ├── Папка2/
       │   └── мультик3.mp4
       └── Папка3+/
           └── мультик4.mp4
     ```
   - Папки с символом `+` в названии требуют дополнительного задания (ввод команд Linux)

### Шаг 4: Установка omxplayer (если не установлен)

```bash
sudo apt-get update
sudo apt-get install omxplayer
```

## Использование

### Запуск программы

```bash
./typer.sh
```

### Процесс работы

1. **Инициализация**:
   - Скрипт автоматически создаст директорию `~/typer` (если её нет)
   - Создаст файл `~/typer/wc.t` с начальным значением `10` (количество заданий)
   - Проверит наличие смонтированного USB-накопителя

2. **Математические задачи**:
   - Программа предложит решить примеры на сложение
   - Каждый правильный ответ уменьшает счетчик оставшихся заданий
   - Неправильный ответ увеличивает счетчик (делает задание сложнее)
   - Команда `reset` сбрасывает прогресс текущей сессии

3. **Изучение команд Linux** (для папок с `+`):
   - После выбора папки с символом `+` в названии
   - Программа попросит ввести одну из команд: `sudo`, `mkdir`, `nano`, `less`, `rm`, `echo`, `touch`
   - Необходимо правильно ввести команду для продолжения

4. **Выбор мультфильма**:
   - После выполнения всех заданий отображается список доступных папок с видео
   - Введите номер папки для выбора
   - Программа случайным образом выберет видео из выбранной папки

5. **Воспроизведение**:
   - Видео воспроизводится через `omxplayer`
   - После завершения воспроизведения скрипт автоматически перезапускается

## Конфигурация

### Изменение количества заданий

Отредактируйте файл `~/typer/wc.t`:

```bash
nano ~/typer/wc.t
```

Введите желаемое количество заданий (например, `15`).

### Изменение пути к видео

Отредактируйте переменную `vfolder` в скрипте (строка 74):

```bash
vfolder="/media/pi/HOME128/Videos/"
```

### Изменение пути к USB-накопителю

Отредактируйте проверку директории в скрипте (строка 17):

```bash
if [ ! -d /media/pi/RASPBERRYPI ]; then
```

### Добавление команд Linux

Отредактируйте массив `addons` в функции `addon()` (строка 54):

```bash
addons=("sudo" "mkdir" "nano" "less" "rm" "echo" "touch" "cat" "ls")
```

## Как это работает

### Алгоритм работы

1. **Проверка окружения**:
   - Проверяется наличие директории `~/typer`
   - Проверяется наличие файла счетчика `wc.t`
   - Проверяется наличие USB-накопителя

2. **Математический блок**:
   - Генерируются случайные числа от 1 до 5
   - Пользователь вводит ответ
   - Счетчик прогресса обновляется в зависимости от правильности ответа

3. **Система прогресса**:
   - После каждого успешного прохождения количество заданий увеличивается на 1
   - Значение сохраняется в файл `wc.t`

4. **Блок команд Linux**:
   - Активируется только для папок с символом `+` в названии
   - Рекурсивная функция проверяет правильность ввода команды

5. **Воспроизведение видео**:
   - Используется `omxplayer` для аппаратного ускорения на Raspberry Pi
   - После завершения скрипт рекурсивно перезапускается

### Переменные окружения

- `~/typer/wc.t` — файл с количеством заданий
- `~/typer/` — рабочая директория скрипта
- `/media/pi/RASPBERRYPI` — путь к USB-накопителю данных
- `/media/pi/HOME128/Videos/` — путь к папке с видеофайлами

## Устранение неполадок

### Проблема: "NO USB DRIVE MOUNTED!"

**Решение**:
1. Убедитесь, что USB-накопитель подключен
2. Проверьте точку монтирования: `ls -la /media/pi/`
3. Если накопитель смонтирован в другом месте, измените путь в скрипте (строка 17)

### Проблема: "Permission denied"

**Решение**:
```bash
chmod +x typer.sh
sudo chown pi:pi ~/typer
```

### Проблема: omxplayer не воспроизводит видео

**Решение**:
1. Проверьте установку: `which omxplayer`
2. Установите заново: `sudo apt-get install omxplayer`
3. Проверьте формат видео (рекомендуется MP4, H.264)

### Проблема: Не отображаются папки с видео

**Решение**:
1. Проверьте путь: `ls -la /media/pi/HOME128/Videos/`
2. Убедитесь, что папки содержат видеофайлы
3. Проверьте права доступа: `chmod -R 755 /media/pi/HOME128/Videos/`

### Проблема: Скрипт не создает директорию

**Решение**:
```bash
sudo mkdir -p ~/typer
sudo chown pi:pi ~/typer
```
